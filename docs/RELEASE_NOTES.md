# 3.2.0-rc.1 — preview with limitations

Два завершені українські огляди з адресною редакцією R01–R44, зі збереженням E01/E02. Отримано 11 зовнішніх PDF і прочитано визначені сторінки; actual hashes відокремлено від повідомлених. Обидва формати відтворюються з одного рукопису, точних шрифтів і pinned toolchain.

Статична початкова сторінка ставить огляди першими. Чотири версійні приклади ведуть із розділу до конкретного механізму й назад. Їхній стан відокремлено від особистого демо. Збережені старі PDF/HTML-шляхи, hash-маршрути, схеми та ID.

Виправлення цілісності інтегровано з окремого PR; точний included-heads і перевірки формуються в candidate-manifest.json з конкретного GitHub SHA. Manifest описує реальні outputs; не є незалежною рецензією чи доказом достовірності джерел.

Залишки: untagged PDF / R42 #4; stable Safari/фізичний iPhone #1; реальний browser zoom і VoiceOver; пояснення відліку сервісних строків R34. Широкий SEO #2 не прийнято й не включено. Інтеграцій із реальними API, замовлень і міграції framework/hosting немає.

Main і чинний Pages не оновлено. Абсолютні PDF/OG URLs указують на погоджений publication origin; нові case-сторінки до дозволеної публікації доступні в HTTP-preview з artifact. Не позначати випуск stable/latest. Наступний крок — read-only приймання точного кандидата координаційним чатом і незалежним рецензентом.
