# Публікація

Стан: **BLOCKED_GITHUB_AUTH**. Репозиторій, Pages, tag і Release цього перенесення ще не створено або не підтверджено.

GitHub CLI 2.101.0 встановлений, але `gh auth status --hostname github.com` не підтвердив входу; `gh api user --jq .login` завершився кодом 4. Підключення розпізнає mathewfromua, однак `get repository` та фактична спроба `create blob` для цільового репозиторію повернули HTTP404. Це не доказ відсутності репозиторію: можливе обмеження доступу. У підключенні немає операції створення репозиторію або налаштування Pages. Браузер відкрив сторінку входу GitHub.

Очікувана адреса з deployment.config.json — конфігурація кандидата, не підтверджена публікація. Після авторизації: прочитати наявний repo → створити або недеструктивно доповнити → push main → увімкнути Actions Pages → отримати page_url → звірити HTTPS-байти й дії. Старий Sites збережений без змін.
