# Modern Experience: реалізовані межі

Ця гілка походить від технічно перевіреного RC2 `0034b000bd1bad42f0c3ffb222a0ec58308a42bc`. Вона не змінює release-гілку автоматично. Два українські огляди залишаються основним продуктом; їхні готові PDF/HTML та рукопис збережено.

## Збірка і статична публікація

Vite 8.3.4 обробляє native ESM, TypeScript, JSX, CSS і dynamic imports. `scripts/build-static.mjs` більше не переписує import-шляхи власними регулярними виразами: він викликає Vite та після компіляції формує статичний hub, `demo.html`, чотири вкладені адреси кейсів, `publication.json` і manifests. Точні залежності фіксує `package-lock.json`; Node 24 і `npm ci` відтворюють встановлення.

Hub має окремі CSS та малий legacy redirect, без каталогу й React. Демо завантажує чинний каталог; компонент React підключається динамічно лише на маршруті нового порівняння. Це зменшує обсяг коду, потрібного читачеві оглядів; швидкодію оцінюють вимірювання, а не сама назва збирача.

`BASE_PATH=/` та `/asp24-nggroup-demo-research/` задають кореневе й Pages-розміщення. Preview-сервер віддає реальні статичні файли й 404 для неіснуючих шляхів, без SPA fallback. Canonical/OG/noindex, MIME, посилання, точні байти PDF/HTML, allowlist, Vite-граф і SHA-256 ресурсів перевіряє `npm run verify`. HTTP-тести обох base paths збережено, додано негативну перевірку зміненого compiled asset.

## Домен, дані та адаптери

- `src/domain/`: типізовані правила каталогу, сортування, порівняння, кількостей, сум і відновлення стану. Domain не імпортує React, DOM або browser storage.
- `src/data/`: перевірена межа синтетичного каталогу з явною версією JSON та stable ID; схожість назви/SKU не визначає ідентичність.
- `src/adapters/`: збереження та зовнішні формати. Збережено schema 4, `perspective-demo-v1`, project import version 1 і RC2-контракт sessionStorage для ізольованих кейсів.
- `src/ui/`: React Comparison Workbench і його типізований міст до стану застосунку. Компонент тримає тільки тимчасовий стан взаємодії, а зміни кандидатів, пари й короткого списку проходять через спільні правила та збереження.
- `src/styles/`: CSS простору порівняння з адаптивними режимами, видимим фокусом і окремими палітрами ASP24/NG Group.

Кореневі JS-експорти збережено для чинних компонентів і Node-тестів. Нові TS/TSX-модулі перевіряються `strict` окремою командою `npm run typecheck`; решта старого JS підключається поступово через `allowJs` без твердження про повну типізацію всього проєкту. Vite-транспіляція не зараховується як typecheck. Node 24 виконує доменні TS-модулі без окремого test transpiler.

Параметри розрізняють відоме значення (включно з 0/false), невідоме, пропущене, незастосовне та суперечливе значення. Runtime-валідація перевіряє зовнішній JSON; TypeScript не замінює перевірки вводу.

## React pilot і сумісність

Новий простір доступний з чинного порівняння та напряму: `demo.html#/asp/compare?experience=modern` / `#/ng/compare?experience=modern`. Legacy-порівняння лишається контрольним поданням тих самих даних. Пілот дає пошук і добір до шести кандидатів, окрему пару A/B, заміну, видалення з undo, перегляд відмінностей/повного набору та короткий список закупівлі. Єдина схема стану забезпечує повернення між поданнями й reload.

Desktop використовує ширину робочої області для значень поруч; mobile — активну пару й явні A/B. Доступність перевіряється клавіатурою, семантичними таблицями, focus, reflow 320/390/430/1440 CSS px і CSS text stress 200%. Це не результати native zoom, Safari, iPhone або VoiceOver.

## Вимірювання і передача

Новий workflow `modern-preview.yml` прив’язує build, браузерні suites і повторні вимірювання до точного SHA. Baseline — RC2 `0034b000…` у тому самому CI-середовищі. Вимірюються ресурси, compressed bytes, запити, LCP, CLS та лабораторний час взаємодії; окремо зберігаються Lighthouse-результати, якщо запуск відбувся. PASS вимірювання означає отримані дані, а не гарантоване прискорення.

`modern-manifest.json` у HTTP-preview artifact містить SHA, результати та hashes усіх файлів. Packaging не перебудовує dist і вимагає відповідності вже перевіреним байтам. Немає backend, SSR, БД, платного хостингу чи надсилання реальних замовлень. Merge/deployment лишаються окремим рішенням власника.

R42 досліджується окремим повним tagged-експортом. До змістової, структурної й візуальної перевірки цей експеримент не замінює чинні PDF і не закриває PDF/UA. R34 також залишається відкритим.
