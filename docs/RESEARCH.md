# Метод і межі висновків

Огляди поєднують датовані спостереження інтерфейсу, збережені DOM/HTML-витяги, історичні порівняння, фрагменти документів та явно позначені рекомендації. Тип і дата доказу лишаються поряд із джерелом. Відсутність первинного файла не перетворює історичне повідомлення на спростований епізод, але обмежує незалежну повторну перевірку.

| Матеріал | Межа |
|---|---|
| Картка або видима кнопка | Підтверджує прочитаний вміст, але не виконання дії. |
| Кешоване текстове вебподання | Не є новим live-сценарієм, скриншотом усіх сторінок або перевіркою актуальної ціни. |
| Офіційна документація Google | Пояснює правила, але не доводить конфігурацію ASP24/NG Group. |
| Наявність sitemap або відсутність noindex | Не встановлює фактичну індексацію, позиції чи трафік. |
| Історичний Open Graph amount=1 | Зберігає історичну атрибуцію; не називається Google Offer або поточною ціною. |
| Матеріали DEPS/ROMSAT | Приклади механізмів, а не загальний рейтинг магазинів. |
| Синтетичне демо | Показує запропоновану взаємодію, але не доводить економії часу, конверсії чи технічної сертифікації. |

Числа 16→9, 14→0 і 30→0 стосуються обраних історичних характеристик конкретних товарів із різними датами. Відбір NG 10→4→2→1 стосується кількості карток, а не воронки покупців. Умовна формула `t = E / P` не є виміряною автономністю: фактичний результат залежить від навантаження, втрат, режиму та виконання. Відсутні значення не прирівнюються до нуля.

Поточні PDF/HTML містять джерельні посилання; [`research/source-register.json`](../research/source-register.json) відтворює атрибуцію з того самого канонічного JSON. Первинні приватні журнали, форми з токенами, облікові дані та повні сторонні архіви не включені до публічного репозиторію.
