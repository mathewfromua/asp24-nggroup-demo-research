## Інваріанти для фінального QA

- Один інтеграційний RC3 від перевіреного актуального PR #8, draft PR на `feat/modern-experience`; PR #7/#8 та main залишаються контрольними точками. Не більш однієї інтеграційної гілки, без force/reset/clean/merge/deploy.
- Одне джерело змісту `reports/content.json`; з нього фактично згенеровано обидва PDF і HTML. Різні viewport/подання не породжують незалежного рукопису. Frozen section IDs не залежать від фізичних PDF-сторінок.
- У PDF/HTML немає необмежених «п’ять виходів» для M1550-C; DC/USB розрізнені; числа 2+1+2 / 1+2+2 / два 12 В збережені.
- FHP12A: NG −10…+70 dBm прямо відділено від різних Grandway; FHP12A/FHP12-A, ревізія/поставка/довжина хвилі не злиті; дата папки URL не редакція документа.
- Нові primary retrieval records містять actual SHA (не хеш URL чи його переказ), дату, фізичні сторінки та обсяг читання. Історичне SECONDARY не зникає. Авторський журнал не стає власною незалежною перевіркою.
- E01/E02 і цільова вибірка залишаються явними. Історичні дати 09–10.09, 28.09, 04/07/09.10 та архівні пари не зведені до одного «актуального аудиту».
- Умовні 6570 + 10380 = 16950 грн; 2×305 = 610 м; 57,72/13≈4,44 год, /15≈3,85 год. Без нових причинностей, фізичних тестів чи реальних цін.
- R34 OPEN; R42 OPEN; гарантійне обладнання назване. PDF untagged чесно зазначені; HTML семантичний, а не обіцянка PDF/UA.
- 384 моделі, 13 виробників, 8 категорій, 6 кандидатів і пара; schema 4, import v1, stable IDs, storage `perspective-demo-v1`, ліміт 64, undo/recovery, точні одиниці/кількості/суми без регресій.
- unknown/missing/not applicable/conflicting не стають нулем. Демонстраційний D1 не доводить застосовності реального документа або проходу різних ревізій.
- Чотири versioned та чотири alias cases доступні в HTTP-preview, правильний return до frozen section; особисті чернетки, кошик і проєкти ізольовані від session-кейсу.
- Контроль first technical row виконується саме на `/cases/six-candidates/v1/` з modern, 1440×900 і 390×844, з окремими скриншотами і координатою нижнього краю повного рядка. Не зараховувати ціну як технічну характеристику.
- Roundtrip modern→картка/документ→посилання/Back→modern: шість/пара/differences/категорія/стан та `experience=modern` збережені. Перевірити також повернення до того самого розділу HTML.
- Undo U05→U07 повертає U05 у той самий слот та попередню пару; інші групи, кошик і drafts збережені. Перевірити заміну активної сторони пари, а не лише неактивного кандидата.
- HTML: бренд у h1, коректні lang/headings/табличні scope/focus, унікальні назви scroll regions, citations ведуть до потрібного запису; SVG на 320/390 CSS px має читабельні числа. Клавіатурні дії перевірені в доступному браузерному середовищі.
- Контраст дрібного тексту на світлих блоках перевищує 4,5:1 з запасом; реальні рендери всіх змінених PDF-сторінок не мають обрізання/перекриття; обкладинки й незмінні фрагменти звірені.
- Фінально npm ci/typecheck/test/build/verify; Chromium/Firefox/WebKit, root і Pages subpath, HTTP кейсів, контроль PDF/HTML, digest та негативні stale-output checks. Старі PASS не переносяться на новий SHA автоматично.
- WebKit ≠ native Safari; фізичний iPhone/native zoom/VoiceOver NOT_RUN за відсутності окремих тестів. Скріншот із maxTouchPoints=0 не доводить touch.
- Exact-SHA artifact містить actual outputs, input/source manifest, hashes, screenshots, validation matrix; без приватних архівів/секретів/кешу/шрифтів. Checksum підтверджує байти, не істинність предметних тверджень.
- Публічні 404 є реальним читацьким обмеженням до дозволеної публікації; preview PASS не означає PUBLIC_RELEASE_VERIFIED. Після дозволу потрібні анонімні HTTPS status + delivered SHA для reports, 4+4 cases, demo.html, publication.json, legacy hashes і metadata.

## Нюанси, які легко пропустити

1. Сам RC3 ZIP **не містить** приватні старі research archives. Рецензія перелічує їхні внутрішні шляхи, але це не означає, що вони є в новому вкладенні. Нову primary attribution не можна отримати простим копіюванням твердження рецензента.
2. Технічний рецензент не прочитав самостійно числову таблицю старого FHP12 PDF `/20201102/`; _2024_.pdf і twisted.pdf були сканами без текстового підтвердження реквізитів. Це не спростовує авторського візуального журналу, але й не підвищує його до незалежної перевірки.
3. ASP24 с. 6 не згадує USB у наданому RC2 HTML взагалі. Просто додати «DC» один раз недостатньо для вимоги «не приховуй USB».
4. `first technical row` має бути **повний**, разом із контекстом моделей; top < viewport height недостатньо. Перевірка standalone не закриває контроль case.
5. Зворотне посилання та browser Back — різні сценарії. Додавання redirect може приховати дефект посилання, пошкодивши history.
6. Нетеговані PDF не блокують чесний preview. Рецензійну пораду тегувати слід відкласти згідно з конкретним RC3 contract, не замінювати PDF експериментом автоматично.
7. Старий Chromium interaction FAIL на 1e18776 виправлений на a659d2f; не переносити його як чинний дефект. Водночас PASS старого SHA не є власною RC3 перевіркою.
8. Розширення джерел і доповнення USB можуть змінити пагінацію. 14/16 сторінок бажані, але не виправдовують стискання кегля; stable IDs зберігаються незалежно.
