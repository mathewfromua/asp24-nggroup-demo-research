# Фінальне технічне зміцнення RC3

Контрольна база: `b320abc302ed895704db2437ce7dbe3a6964e603`, PR #9,
CI `37929590198`, artifact `11614914429`. Незалежне рішення для цієї бази —
`ACCEPT_PREVIEW`. Воно не переноситься на новий SHA автоматично.

Робота продовжується в `release/review-integrated-rc3`; main, Pages, Settings,
merge і deployment не входять до дозволеного обсягу. `reports/content.json`
залишається прийнятим редакційним джерелом без переписування висновків.

## Обсяг

- Структурований PDF-експорт на основі наявного WeasyPrint experiment із
  початковими векторними/текстовими обкладинками, логічними тегами та належною
  пагінацією. Заміна публічних PDF лише після перевірки обох чернеткових виходів.
- Доступна альтернатива JSON/TXT download і clipboard; правдивий статус сховища;
  навігація та документи при відмові завантаження Workbench.
- Контекст довгих таблиць, фокус активної пари desktop та читабельність підписів.
- Зменшення початкового завантаження наявного Workbench без зміни стеку чи схем.

Перевірки під час реалізації адресні. Єдиний узгоджений повний gate після
інтеграції перевіряє незмінний dist точного push-SHA в трьох рушіях; нові
перевірки доповнюють, а не замінюють попередні regression suites.

## Реалізовано і перевірено перед exact-SHA gate

Обидва PDF замінено лише після незалежного читання всіх 30 сторінок,
перевірки логічної структури й повноти 226 + 252 змістових блоків. Збережено
14/16 сторінок та векторні текстові обкладинки. `content.json` незмінний;
HTML також залишився побайтово незмінним. Фактичні PDF hashes і результати
наведено в `reports/hardening-pdf-acceptance.json` та `rc3-visual-review.json`.

R42 — `CLOSED_STRUCTURAL_TAGGING`: H1/H2/H3/P, TH/TD зі зв’язками заголовків,
Figure/Alt із повними даними графіків, Caption, порядок читання, посилання,
закладки й `uk-UA` підтверджені. veraPDF 1.30.3, профіль PDF/UA-1: обидва
`compliant=true`, нуль помилок. Це машинна валідація, а не твердження про
перевірене читання всіма допоміжними технологіями. Окремих спискових блоків
у рукописі немає; списки всередині ілюстрацій передано їхніми альтернативами.

Експорт завжди залишає точний JSON/TXT на сторінці; відмова Clipboard має
ручний fallback. Відмова Storage видима; чужий storage event не затирає
поточну незбережену чернетку. При відмові React доступні classic, каталог,
документи й огляди. Завершення старого lazy import не підмінює новіший діалог.

Таблиці зберігають назви моделей і параметрів; «Лише пара A/B» залишає всі
шість кандидатів. Допоміжні підписи збільшено. Режим пари та позиції таблиці
й сторінки зберігаються через картку, документ, Back/Forward і reload.
Адресний незалежний перегляд підтвердив виправлення втрати контексту читання
та перехоплення новішого діалогу відкладеною дією. У WebKit manual scroll
відновлюється на кожному переході історії; корекція фокуса допомагає клавіатурі
й не зсуває ціль натискання мишею. Відновлення після HTTP 503 використовує
обмежений токен адреси того самого модуля, щоб наступний reload не повертався
до закешованої помилки. Постійна відмова зберігає документи, стан і явний retry.

Проєкти й лабораторія завантажуються на вимогу; Workbench починає своє
завантаження паралельно з підготовкою explicit modern route. Каталог і
доменна логіка не дублюються. Порівняння продуктивності виконується на одному
runner з прийнятим `b320abc…`: 5 парних повторів трьох сценаріїв, свіжі
контексти, однаковий gzip/HTTP і відсутність throttling. Реальні значення
нового SHA містяться в `evidence/browser/chromium/performance/hardening-comparison.json`
артефакту. Відкладений перший перехід до проєктів — явний компроміс;
загального прискорення чи польових Web Vitals не заявлено.

Контракти незмінні: `perspective-demo-v1`, schema 4, import version 1,
384 моделі / 13 виробників / 8 категорій, 24 на сторінку, шість кандидатів,
активна пара й 64 позиції в проєкті. Нові дані лише про вигляд зберігаються
в чинному `view.pages`, із перевіркою типів і меж; окремої системи кандидатів
не створено. Кейси та їхні aliases залишаються ізольованими від особистих даних.

## Нативні середовища: короткий smoke-test для власника

Для нового SHA окремо виконати на Safari macOS/iOS, Chrome Android,
Telegram iOS/Android та потрібному WKWebView/Android WebView. Linux Chromium
і Playwright WebKit не підтверджують ці середовища. Записати версію ОС,
браузера/застосунку, пристрій, exact SHA, результати й знімок проблеми.

1. Через HTTP(S) відкрити hub, обидва HTML та PDF; повернутися до hub.
2. Знайти `DEMO-U02`, застосувати фільтр і відкрити картку. Екранна клавіатура
   не повинна закривати активне поле й основну дію; закрити її та повернутися.
3. Відкрити `cases/six-candidates/v1/`: перевірити шість кандидатів, пару A/B,
   перший технічний рядок, заміну U05→U07, undo, Save і reload.
4. Відкрити картку/документ із modern, повернутися посиланням, Back і Forward:
   режим, категорія, кандидати, пара та відмінності повинні зберегтися.
5. У NG відкрити DEMO-U02/D1, змінити чернетку запитання, повернутися до тієї
   самої моделі й перезавантажити. Особисті кошик/чернетки не змінюються кейсом.
6. Експортувати JSON і TXT, перевірити фактичний вміст файла й копіювання.
   Якщо download/clipboard обмежені, скопіювати точний текст через доступну
   альтернативу на сторінці. Пропозиція download не означає, що файл збережено.
7. У доступному обмеженому/приватному контексті перевірити відмову сховища:
   видиме повідомлення «лише в пам’яті», поточні зміни доступні для експорту.
   Не використовувати особисті робочі дані й не надсилати реальних звернень.

До фактичного виконання статус кожного такого середовища — `NOT_RUN`,
незалежно від результату WebKit CI. Допоміжне читання PDF/VoiceOver також
обліковується окремо від машинної PDF/UA-валідації.

## R34 — OPEN_EXTERNAL_SOURCE

Погоджений текст лишається обережним: до 14 календарних днів для діагностики
й ремонту гарантійного обладнання; від двох тижнів до трьох місяців у випадку
передавання виробнику. Початок відліку та вкладеність строків не встановлені.

Одне питання відповідальному за сервіс, **підготовлено, не надіслано**:

> Від якої події відраховуються 14 календарних днів і строк від двох тижнів
> до трьох місяців, та чи включає другий строк початкову діагностику?

Без належної офіційної відповіді R34 не закривається. Це не блокує незалежну
технічну розробку PDF, UI та browser fallbacks.

## Межі остаточного рішення

Результати нового SHA, exact-SHA artifact, машинна PDF-валідація, незалежне
читання змінених PDF/UI та порівнювані performance-виміри додаються після
завершення gate. До цього новий кандидат не успадковує попередній PASS.
Публічна HTTPS-перевірка можлива лише після окремо дозволеного deployment.
