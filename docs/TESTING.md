# Перевірки та відомі межі

`npm test`, `npm run build` і `npm run verify` перевіряють різні речі: логіку, створення статичних активів та їхню узгодженість. Кожний новий запуск записується окремо від попередніх результатів. Поточні фактичні результати — у `RESULTS.md`.

До публічної міграції були датовані часткові проходи Safari 27.2 (22625.2.7.1) на macOS 27.2 beta (26B5101f). Вони охоплювали частину фільтрів, чернеток, сум і переходів. Це історичне середовище; воно не засвідчує поточну стабільну Safari, попередню підтримувану OS або фізичний iPhone. Пізніші тайм-аути засобу керування браузером — BLOCKED, а не дефект застосунку.

У міграційному проході доступний in-app browser на ширині 390 CSS px уже пройшов вибір пари U05/U06 із шести кандидатів та reload у двох режимах. Це окремий браузерний результат для вузького viewport, не тест Safari або фізичного iPhone. Повний набір поточних результатів та пов’язана збірка записуються у `RESULTS.md`.

## Залежні функціональні сценарії

| Дія | Очікуваний результат |
|---|---|
| OR 18/36 → прибрати тільки 18 | Лишається 36; решта умов, sort і подання збережені. |
| Незбережена назва/примітка → кандидат → кількість | Чернетка не зникає; Save → справжній reload відновлює запис. |
| VOLTYN N36, price-down | 2490 перед 2190; лічильник кошика змінюється відразу. |
| Шість кандидатів → мобільна пара → заміна → remove/undo → reload | Обидві позиції керовані; інші кандидати та режим збережені. |
| U02 × 3 і C04 × 2 | 6570 грн; 610 м / 10380 грн; разом 16950 грн, без змін після reload. |
| DEMO-U02 / D1 → документ → питання → ASP24 | Той самий ID і виконання, чернетка збережена. |
| Clipboard denied, storage denied/quota, невалідний JSON | Зрозумілий результат, без хибного «збережено» чи мовчазної втрати даних. |

## Окремий короткий прохід iPhone

Адреса для цього протоколу: https://mathewfromua.github.io/asp24-nggroup-demo-research/ — публікацію перевірено 09.10.2026. Запишіть модель телефона, версії iOS/Safari, layout/visual viewport, орієнтацію та hash збірки.

1. Додайте шість моделей до порівняння, оберіть обидві позиції пари, замініть одну, виконайте remove/undo й reload. Перевірте кандидати та режим.
2. З відкритою системною клавіатурою відредагуйте довгу назву й примітку; перевірте прокручування, нижні кнопки діалогу, закриття та повернення фокуса.
3. Пройдіть документ → модель → чернетка питання → ASP24, потім Back/Forward. Відкрийте PDF, поверніться, переведіть Safari у фон і відновіть його.
4. Перевірте портрет/альбом, safe areas, браузерні панелі, pinch zoom, збереження PDF/експорту у «Файли», імпорт і зрозуміле повідомлення після відмови в копіюванні.

Для кожного пункту потрібні кроки, очікування, фактичний результат і кадр або журнал. Фізичний iPhone наразі не прийнятий; симулятор чи вузьке вікно не змінюють цього статусу. Клавіатурна навігація й VoiceOver перевіряються окремо.
