# Відбір публічного дерева

Перевірено перелік підготовлених Git-файлів, зміст поточних README/RESULTS, джерело звітів, атрибуцію й залежності генераторів. До імпорту включено чинні модулі, тести, готові звіти, їхнє джерело, короткі дозволені фрагменти й карту джерел. Private hosting/session/Cookie-дані, абсолютні шляхи Mac, LAN-адреси, повні старі ZIP/PDF, зайві ілюстрації, шрифтові файли й кеші не включено. Автоматичний пошук приватних шляхів та шаблонів ключів — допоміжна перевірка; рішення про відбір не спиралося лише на нього.

Фактичний GitHub push не виконано. Цей запис описує локально підготовлене дерево.
