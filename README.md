# ASP24 / NG Group — Demo & Research

Демонстраційний каталог і два аналітичні огляди того, як знайти товар, зіставити його характеристики та зберегти результат вибору.

ASP24 показує шлях від запиту й добору до порівняння, кількості та локального списку закупівлі. NG Group пов’язує модель, її виконання, технічний документ і чернетку запитання з відповідним товаром ASP24.

**Це демо.** Каталог містить 384 синтетичні моделі, 13 умовних виробників і вісім категорій. Ціни та характеристики слугують сценаріям інтерфейсу. Замовлення й запитання не надсилаються компаніям; записи зберігаються у браузері.

## Локальний запуск

Потрібний Node.js 22 або новіший. Runtime npm-залежностей немає. Готові звіти вже включені: для запуску демо Python і шрифтові файли не потрібні.

```sh
npm run build
npm test
npm run verify
npm run preview -- --host 127.0.0.1 --port 8000
```

Відкрийте адресу, яку надрукує preview: типово `http://127.0.0.1:8000/asp24-nggroup-demo-research/`. Для кореневого розміщення перед build задайте `BASE_PATH=/ PUBLIC_BASE_URL=https://mathewfromua.github.io/`. Потрібний HTTP-сервер: відкриття `index.html` через `file://` не відтворює роботу ESM і сховища.

## Структура

- Кореневі JS/CSS-модулі — каталог, маршрути, порівняння, проєкти та локальне оформлення.
- `public/` — активи демо й готові огляди; `dist/` створюється під час build.
- `reports/` — єдине джерело тексту, генератори, фігури та обкладинки.
- `tests/` — перевірки логіки; [docs/TESTING.md](docs/TESTING.md) пояснює межі браузерного приймання.
- `research/` — публічна карта джерел і прийняті редакційні рішення, без приватного дослідницького архіву.
- [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md) — генерація PDF/HTML; [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) — атрибуція та межі повторного використання.

## Основа й межі

Публічне дерево підготовлено з Checkpoint 03 редакції 3.1.1-rc.1. Збережено E01 — розрізнення M1550-C та акумулятора за артикулами; E02 — усунення повтору про XPON зі збереженням повної атрибуції джерела. Початкові 64 stable ID/SKU та одиниці збережено. Порівняння тримає шість кандидатів і окрему мобільну пару; фільтри, сортування й пагінація працюють із повним результатом. Дані сховища прив’язані до origin: зміна домену не переносить їх автоматично. Перед переходом можна скористатися експортом; успішність імпорту треба перевірити окремо.

Історичні проходи Safari/macOS beta не засвідчують підтримку стабільної Safari або фізичного iPhone. Нові результати мають власну дату, середовище й ідентичність збірки. PDF мають `Lang=uk-UA`, але надійне тегування не підтверджене; семантичний HTML доповнює їх. Сертифікації PDF/UA або повної WCAG-відповідності не заявлено.
