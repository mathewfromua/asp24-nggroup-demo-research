# Повідомлення про безпеку

Це публічне дослідження та локальне синтетичне демо; реальних платежів і серверного приймання форм немає. Не вводьте особистих даних.

[GitHub Issues](https://github.com/mathewfromua/asp24-nggroup-demo-research/issues) придатні для несекретного відтворення проблеми на синтетичних fixtures. Не публікуйте токени, cookies, приватні записи або чутливий доказ. Окремий перевірений приватний канал і гарантований строк відповіді зараз не заявлені. Відсутність security alert не є аудитом безпеки.
