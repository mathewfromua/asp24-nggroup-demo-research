# Публічна дослідницька основа

Ця папка пояснює джерела й редакційний відбір двох поточних оглядів. Вона не є повним приватним досьє, новим обходом магазинів або завершеним широким SEO-дослідженням.

- [ACCEPTED_DECISIONS_UA.md](ACCEPTED_DECISIONS_UA.md) — прийняті E01/E02 та межі майбутніх доповнень.
- [Метод і межі](../docs/RESEARCH.md) — що доводять різні типи матеріалів.
- [source-register.json](source-register.json) — точні URL і формулювання атрибуції з актуального `reports/content.json`.

Публічні джерела можуть змінюватися або бути недоступними. URL сам собою не підтверджує нинішній вміст. Посилання на історичні спостереження зберігають їхні дати; відсутні сирі файли не оголошено відновленими.
