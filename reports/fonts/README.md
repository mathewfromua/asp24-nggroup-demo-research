# Шрифти для повторної генерації

Шрифтових файлів у репозиторії немає. Готові PDF містять потрібні вбудовані гліфи й не потребують встановлення шрифтів для читання.

Генератор використовує `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` та `DejaVuSans.ttf`. Джерело, версії, ліцензія та SHA-256 записані в `provenance.json`. Установіть `REPORT_FONT_DIR` на директорію з доступною вам відповідною копією цих файлів. Старе ім'я змінної `PERSPEKTYVA_FONT_DIR` також підтримується для сумісності локальних збірок.

Для тотожності байтів потрібні ті самі версії шрифтів і генераторів. Після зміни залежностей перевірте переноси та всі сторінки. Обкладинки з `reports/covers/` зберігають власну вбудовану типографіку.
